# Canart Template Center

Canart 网站设计模版中心 — 按行业分类的高质量网站设计模版集合，涵盖 20+ 行业场景，开箱即用。

每套模版均为纯 HTML / CSS / JS 实现，无需框架依赖，下载即用。

## 使用方式

1. 浏览预览图文件夹，快速选择适合的模版风格
2. 进入对应模版文件夹，下载全部文件
3. 本地打开 `index.html` 即可预览完整页面
4. 根据品牌需求修改文案、配色、图片和布局

## 技术栈

- 纯 HTML5 + CSS3 + Vanilla JavaScript
- 无框架依赖，零构建步骤
- 响应式设计，适配桌面端与移动端
