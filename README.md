# Canart Template Center

Canart 网站设计模版中心 — 按行业分类的高质量网站设计模版集合，涵盖 20+ 行业场景，开箱即用。

## 目录结构

```
canart-template-center/
├── Template-css/          # 进阶模版（含交互动效）
├── Template-css-Basic/    # 基础模版（轻量简洁）
├── Template预览图/          # 各行业模版预览图
└── README.md
```

## Template预览图

`Template预览图/` 文件夹按行业分类存放各模版的设计效果图，方便快速浏览选择。

## 使用方式

1. 浏览对应行业文件夹，选择适合的模版
2. 下载模版文件，本地打开 `index.html` 即可预览
3. 根据品牌需求修改内容、配色和图片
